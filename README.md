# ForexChain

ForexChain is a dynamic, lightweight, and fully open-source trading platform designed to offer seamless experiences in both cryptocurrency and forex markets.

## Features

- **User Authentication**: Secure login and registration system.
- **Real-time Trading**: Live price charts and order execution.
- **Multi-Market Support**: Trade both crypto and forex assets.
- **Wallet Functions**: Deposit, withdraw, and manage your balance.
- **Commission System**: Simple broker-like fee structure per trade.
- **Responsive Interface**: Works smoothly across mobile and desktop.
- **Fully Client-Side**: No server required — deploy easily on GitHub Pages.

## Technologies Used

- HTML5, CSS3, JavaScript (Vanilla)
- Chart.js for live trading charts
- LocalStorage for account/session management

## Getting Started

1. Clone the repository or [download as ZIP](https://github.com/yamentradi/forexchain-/archive/refs/heads/main.zip).
2. Open `index.html` in your browser.
3. Register an account and start trading virtually.
